# 15.4 — Assigned staff quote drafts

Assigned operations staff with a live workforce session and TOTP within five minutes may read
customer RRPs and prepare a non-payable draft from quantities and existing scoped delivery/address
references. No price, credit, tenant, patient, paid or approval flags are accepted from the browser.
Drafts retain immutable catalogue, item, delivery and encrypted-address references, actor, case
version and request fingerprint. A new draft version supersedes rather than edits history.
Case locks serialize competing drafts; expected draft/case versions reject stale commands.
Exact retries remain subject to current authority and current reference validity.

This preparatory command is intentionally separate from 15.1's eventual approved quote command:
it does not accept a clinical approval ID, mint a payable offer, reserve credit, change case state,
send a notification or create a provider order. Tasks 15.5/15.6 own approval and issue.
Existing approved encrypted address/delivery bindings are required; no tariff or plaintext address
is invented. Their capture/key custody and recovery remain activation requirements.

Work-context labels come from the authorised tenant's database display name; the label is not
authority. Tenant/role selection still uses the existing exact IDs and approved memberships.
New endpoints remain disabled by default. No hosted migrations or release are authorised here.
